# ADR-006 模型供应商与嵌入模型

状态：模型供应商已确认（2026-10-30）；嵌入模型已确认默认 `text-embedding-v4` + 1024 维（2026-10-30），并已于 2026-10-31 实际调用验证（见文末），可以据此写 `kb_chunk` 迁移。

## 决定
- 接入的大模型供应商：DeepSeek、通义千问 Qwen（阿里云百炼）、OpenAI GPT 系列。不接入 Anthropic Claude。
- 嵌入模型：阿里云百炼文本嵌入。**已确认默认 `text-embedding-v4`，1024 维**；`kb_chunk.embedding` 暂按 `vector(1024)` 设计，写入迁移前仍须按下文完成实际调用验证。
- 候选型号与维度（来源：团队提供的百炼文档摘录，**未对照官方页面逐项核实；`text-embedding-v4` 在 1024 维下已于 2026-10-31 实际调用验证（见文末），其余型号与维度仍未验证**）：

| 模型 ID | 支持的向量维度 | 默认维度 | 说明 |
|---|---|---|---|
| `text-embedding-v4` | 64、128、256、512、768、1024、1536、2048 | 1024 | 通用文本向量，适合新建 RAG 索引（候选默认） |
| `qwen3.7-text-embedding` | 256、512、768、1024、1536、2048、2560 | 1024 | 官方推荐的文本向量模型，可与 v4 做检索对比 |
| `qwen3.7-text-embedding-flash` | 256、512、768、1024 | 1024 | 轻量版，侧重成本与吞吐 |
| `text-embedding-v3` | 文档口径不一致（64–1024 与 512–1024 两种说法） | 1024 | 仅旧索引迁移时可能用到，使用低维前须实测 |

- 一般场景用 1024 维；存储受限可考虑 256 或 512，追求精度可考虑 1536 或 2048，但维度越高存储与计算开销越大。
- **三处维度必须一致**：`kb_chunk.embedding` 的 `vector(N)` 列、写入时的向量维度、查询时的向量维度。改维度或改模型都要重建索引，因此在第一个知识库迁移之前定稿。
- 采用前的验证（A，写迁移之前）：对照官方页面确认型号与可指定的维度；用 1 到 2 条中文样例实际调用接口，确认返回维度与指定一致；再用自己的小知识库检索测试比较 v4 与 qwen3.7。
- 不用于本项目的图文跨模态向量（如 `qwen3-vl-embedding`）：知识库目前是纯文本。
- 模型调用统一经适配器：默认自写薄适配器（统一调用、重试、记录 token、耗时、费用）；LiteLLM 仍为候选，只用其 MIT 部分，是否采用由 B 在实现前评估（尤其国产模型的价格表覆盖）。
- 价格是配置数据，带价格版本，写入 `llm_call_log`；不写死在代码里。
- 密钥只放本地 `.env` 与 CI 的加密变量；CI 不使用真实密钥，模型一律 mock。
- 默认重试（提案，待 A、B 确认）：模型调用失败重试 ≤2 次（指数退避）；约束不通过重新生成 ≤2 次；合规改写 ≤2 轮；均可配置。

## 影响
- P1 的多模型成本对比至少可比较三家。
- 评测须记录模型与提示词版本；真实模型评测不入 CI，手动运行。
- 因客户已允许资料用于开发与演示（ADR-007），资料会发往上述供应商；界面须说明这一点（NFR7）。

## 实际调用验证（2026-10-31）
- 接口：阿里云百炼的 OpenAI 兼容接口 `POST https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings`（国内站）。
- 请求：`model = text-embedding-v4`，`dimensions = 1024`，`encoding_format = float`，输入一句 8 个字的中文。
- 结果：HTTP 200；返回模型 `text-embedding-v4`；**返回向量长度 1024，与请求一致**；用量 7 个 token。
- 因此 `kb_chunk.embedding` 可以按 `vector(1024)` 写迁移；写入与查询都必须显式传 `dimensions=1024`。
- 国际站地址 `dashscope-intl.aliyuncs.com` 本次未用有效密钥测试；密钥按地域区分，部署时要使用与密钥同地域的地址。
- 备注：第一次配置的密钥返回 401（国内与国际站都不认），重新创建后成功。密钥长度（本次约 117 位）**不能**作为判断是否有效的依据，只能靠实际调用。密钥本身不记录在任何文件或提交里。
- 仍待做：用我们自己的小知识库比较 `text-embedding-v4` 与 `qwen3.7-text-embedding` 的检索效果。
