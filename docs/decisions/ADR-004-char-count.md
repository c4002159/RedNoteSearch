# ADR-004 标题字数口径：字素簇

状态：已确认（2026-10-30）；标题 20 字、正文 1000 字的上限已由小红书发布页确认；计数规则（emoji、换行、话题文本是否计入）待实测。

## 决定
- 标题 ≤20 字，按 Unicode 字素簇计数：一个用户可见字符算 1，emoji 序列（含 ZWJ 组合）与带组合重音的字符都算 1。
- 后端为权威：Python 用 `regex` 库的 `\X`；前端提示用 `Intl.Segmenter`，结果以后端判定为准。
- 口径做成可配置项；发布端实测后若不一致，改配置并更新本文件，不改调用方。
- 已验证：在 Python 3.14 下，“带组合重音的字母 + ZWJ 家庭 emoji + 笑脸 emoji + 空格”计为 4。
- 必须有边界测试：20 字与 21 字、emoji、空格、标点、组合字符（TC-016、TC-F05）。

## 发布页显示的限制（2026-10-30，团队提供的小红书图文发布页截图）
| 项 | 上限 | 说明 |
|---|---|---|
| 标题 | 20 | 计数器显示 `0 / 20` |
| 正文 | 1000 | 计数器显示 `0/1000` |
| 图片 | 18 | 计数器显示 `1/18`；本项目不生成图片，不受约束 |

截图里没有看到话题数量的上限；话题通过正文下方的“# 话题”按钮或推荐话题添加。因此约束检查除标题 ≤20 外，**增加正文 ≤1000**，仍按字素簇计数。

## 待实测（在发布页做，结果记在本文件）
1. 标题里放 emoji（含 ZWJ 组合）、空格、换行，计数器各增加多少。
2. 正文的 1000 是否把 `#话题` 的文字也算进去；换行符、emoji 怎么计。
3. 以上结果与字素簇口径不一致时，改配置，不改调用方。
