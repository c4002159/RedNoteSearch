# ADR-008 前端视觉基线

状态：已确认（2026-10-30）。

## 决定
- 前端设计稿由成员 B 按技术文档第 4 章的前端约束和 2.1 功能表制作；成员 A 审阅确认后，落地为 design token 与公共组件。
- 千瓜后台只作布局与交互参考，不决定主色；不复制其标志、配色数值、文案、插图或代码。
- 此前出现的一张“文案工作台”设计稿不作为基线；其中与契约不一致的点（场景与结构模板拆分、受众与重点、高级约束字段、文件上传、帮助与通知入口）在 B 的设计稿中重新决定，需要改契约时按契约变更流程提 PR。
- 开发时 AI 只把设计图当视觉参考；字段、选项、文案以契约、文案模块和接口为准，不由 AI 凭图编写。

## 要求
- B 的设计稿须覆盖：生成工作台、结果页（含证据面板、风险面板）、编辑与复检、确认与复制、错误与 403 状态，以及 A 负责的知识库与审核页。
