# ADR-007 仓库可见性与客户资料

状态：已确认（2026-10-30）。仓库改私有的操作尚未执行。

## 决定
1. 仓库 `c4002159/RedNoteSearch` 改为**私有**，只给 A（c4002159）与 B（CHNERUI）访问。推送初始快照前先完成。
2. 客户已允许品牌手册用于开发与演示，包括输入外部 AI 服务与大模型调用。
3. 仍不得提交到仓库：品牌手册 PDF 原件、截图、API 密钥、`.env`（模板曾提交带 `changethis` 的 `.env`，改为 `.env.example`，CI 生成临时 `.env`）。
4. 种子数据可含从手册提炼的品牌与商品信息，但不放原文大段拷贝；演示界面保留“示例资料不代表真实产品事实”的提示。
