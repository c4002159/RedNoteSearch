# ADR-012 后端分工变更：全部后端由 A 与 AI 助手负责

状态：已确认（2026-10-31）。修订 ADR-001 中“各写各表”里属于 B 的部分，以及技术文档 3.3、5.1、7.2。

## 背景
B 的设计稿与前端页面工作量大，原属 B 的后端（场景、任务、生成、约束、证据、合规、评测、模型适配器及对应表和迁移）无法同时推进。

## 决定
1. 自 2026-10-31 起，原属 B 的后端、数据库、迁移和测试由 A 与 AI 助手负责；P1 的 F12、F13、F14 与规则批量导入同样如此，F15（多模型成本对比）不做。
2. B 负责全部页面的设计稿，并实现生成工作台、结果页、任务与版本历史、评测相关页面；A 与 AI 助手实现应用壳、token、公共组件、品牌与商品、品牌档案、知识库、合规规则维护。
3. 对接只看 `docs/API_CONTRACT.md` 和生成的前端客户端（不手改 `frontend/src/client`）。接口变化在 PR 评论里 @CHNERUI。
4. ADR-001 其余约定不变：迁移线性、只有一个 head、不用 `alembic merge`。

## 影响
- `docs/INTEGRATION_FOR_B.md`、`CLAUDE.md`、`AI_TEAM_GUIDE.md` 已按此更新；B 的助手不实现后端。
