# ADR-013 平台管理员在网页设置模型密钥

状态：已实现，待 B 在 PR 评论里确认（涉及认证与新增依赖 `cryptography`）。

## 背景
接口密钥原来只能放服务器 `.env`，管理员无法在网页里更换密钥或调整模型。要求：必须鉴别身份，密钥不能被读回。

## 决定
1. 只有平台管理员（`is_superuser`）能读写；品牌管理员与普通成员 403。
2. 密钥保存前用 Fernet 加密，密钥由 `SECRET_KEY` 经 HKDF-SHA256 派生；库里只存密文和最后 4 位；接口、日志、审计都不出现明文。
3. 取用顺序：库里的值优先，其次 `.env`。清除网页设置即回到 `.env`。`SECRET_KEY` 变了之后库里的密文读不出，视为没有，回退 `.env` 并记日志。
4. 范围：DeepSeek 的密钥与模型清单、百炼嵌入的密钥。价格、基础地址、超时仍只在 `.env`。
5. 新增依赖 `cryptography`（Apache-2.0 或 BSD 双许可，业界通用的加密库），不自己写加密。
6. 表 `provider_credential`（迁移 `a4c8e2b6d0f3`），审计动作 `settings.provider.update`、`settings.provider.clear`。

## 影响与限制
- 轮换 `SECRET_KEY` 后需要重新填写网页密钥。
- 数据库备份里是密文，但与 `SECRET_KEY` 一起泄露就等于泄露密钥；备份与 `.env` 要分开保管。
- 每次调用模型前会读一次库（一行主键查询）。
