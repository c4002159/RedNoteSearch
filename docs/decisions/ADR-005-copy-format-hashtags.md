# ADR-005 复制格式中的标签写法

状态：已确认（2026-10-30）；发布端识别效果待实测。

## 决定
- `xhs_text` 格式中标签写作纯文本 `#标签`，以单个空格分隔，位于正文之后，空一行。
- 不使用小红书应用内话题的特殊写法（未验证粘贴后是否被识别）。
- 开发中由团队成员在发布端粘贴实测一次，结果记入本文件；若需调整，只改导出格式与契约，不改数据结构。

## 影响
- API_CONTRACT.md 5 节“导出与复制格式”已按此写。
- 测试：TC-042、TC-027。

## 实测步骤（在小红书发布页做，约 5 分钟）
目标：弄清“把 `#标签` 作为纯文本粘贴进正文”会发生什么。
1. 在发布页正文框粘贴：`测试正文 #Softcore #逐帧动画`。
2. 观察：(a) 标签保持普通文字；(b) 被自动识别成话题（变色或可点）；(c) 弹出话题选择。记下是哪一种。
3. 点正文下方的“# 话题”按钮，选一个话题，看它在正文里如何显示。
4. 看正文计数器 `0/1000`：话题文字是否算入字数。
5. 试着添加 6 个以上话题，看是否有数量上限。

## 结果对决定的影响
- 若 (b)：保持现在的 `xhs_text`（标签写在正文末尾）。
- 若 (a)：导出时把标签与正文分开，界面提供“复制正文”和“复制标签”两个按钮，并提示在发布页用“# 话题”添加；契约里 `xhs_text` 只含标题与正文。
- 若 (c)：同 (a)，并在界面写明操作步骤。
