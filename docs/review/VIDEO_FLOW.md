## 一、稳定能演示的主线（可以直接录）

| 步 | 页面 | 点击 | 屏幕上应该看到（我实际看到的） |
|---|---|---|---|
| 1 | `/generate` 生成工作台 | 选商品、场景，写创作要求，“创建并开始生成” | 阶段进度（排队 → 生成中 → 检查中），完成后出现“检查已完成，请查看结果”或“需人工复核”和“查看结果”按钮 |
| 2 | `/tasks/:任务/versions/:版本` 结果页 | 点“查看结果” | 候选标题（带 n / 20）、正文（含话题，n / 1000）、封面文字；右侧“字数与格式检查”“事实依据”“风险提示”三块，各带“不是事实保证”“不是合规结论”的说明 |
| 3 | 同上 | “编辑”→ 改正文 →“保存为新版本” | 变成新的一版，状态“已编辑待复检”；右侧“下一步”写“文字已编辑，需要重新检查…” |
| 4 | 同上 | “重新检查” | 先显示“正在重新检查…”，几秒后自动出现事实依据与风险提示，不用刷新（#89 合并后）；按钮在检查中禁用 |
| 5 | 同上 | 对没有系统依据的断言点“成立”或“不成立” | 弹窗要求填判断依据；之后标注“人工确认（非系统验证）”并带备注 |
| 6 | 同上 | 有“必须修改”的风险提示点“标记为已处理”，写处理说明 | 提示标为“已处理”；在这之前“确认可复制”禁用，并写明“还有 n 条…未处理” |
| 7 | 同上 | “确认可复制” | 状态“可复制（运营已确认）”；出现“复制到小红书”：标题、正文、话题分开复制，另有“Markdown 全文”；写“系统判定支持 n 条，人工确认（非系统验证） n 条” |
| 8 | `/tasks` 任务与版本历史 → 点开任务 | 选两个版本，“对比” | 版本列表和对比页（`/tasks/:任务/compare`）；对比页只比文字差异，没有字数、约束、风险提示的变化（已在烟测清单里记过） |

## 二、规则与知识库（不依赖模型，可以录）

| 页面 | 点击 | 看到 |
|---|---|---|
| `/compliance/rules` 风险提示规则 | 下载模板 → 导入（预览，再合并）→ 导出 → 新建一条规则 | 按设计导入预览有成功与错误行（我这轮只用 API 建了一条自建演示规则并在页面看到它命中，导入导出没重走）；规则带来源、条款、有效期；示例规则显示“来源待核对，不是正式依据”。**只用来源已人工复核的 S1、S2**，S3–S6 仍待核，不要当正式依据讲 |
| `/knowledge` 资料列表与上传 | 管理员“上传资料” | 按设计上传成功后直接“已入库”“可检索”（**这一步我没有实际上传验证**；建索引要嵌入模型，真实录时由 A 录） |
| `/knowledge/review` 待审队列 | 编辑者提交后，管理员审核通过或驳回（驳回理由必填） | 按设计通过前待审资料不会被用于生成（**我只看过空队列，没走过审核**） |
| 编辑者账号看同样的页面 | 切到编辑者 | 没有待审队列、没有“新增商品”、规则页只读；这是“看不到管理入口”的演示 |

## 三、必须用真实模型才有效果的片段（由 A 录）

这些我在假模型下**没有看到真实效果**，不要用假模型录：
- **事实核查的“没有系统依据”**：假模型是文字包含式判断，会给出看起来像样的“系统判定支持”，不代表真实核查。
- **风险提示的模型判断部分**：假模型这一步返回空。词表命中（比如自建规则的关键词）是代码判断，假模型下也能看到。
- **品牌串味测试（F14）**：我没跑过。
- **爆款结构分析（F13）**：本地没有模型，分析窗口显示“没有可用模型”，没走过分析。
- **局部重写**：需真实模型，A 负责。
- **评测运行、事实核查运行、评分保存、一致性**：需真实模型，A 负责；合规评测不需要模型。
