## 3. 全站的已知限制

- **假模型只能证明页面和流程通，不能证明效果。** 事实核查、风险提示的模型判断、局部重写、品牌串味测试、爆款结构分析、评测里需要模型的运行，都没有在真实模型下看过（`VIDEO_FLOW.md` 第三节）。
- **验证环境是单人本地演示库**，数据是自编的“演示”内容；没有在干净环境用真实资料做过整套验证。
- **桌面优先**（4.2 FC-12），≥1280 px 为基准；我没有系统地测过 1024 px 和键盘可达、对比度（FC-11、FC-12），这两项**未验证**。
- **页面里只有 401 会登出**（4.2、HANDOFF）；403、404 显示无权限或没有找到，这点在 G2、H1、H2 看过。
- **禁用措辞**：我看过结果页、规则页、评测页和知识库页的可见文字，没有“合规通过、已验证事实、法务批准、保证合规”；CI 的 `forbidden-wording` 另有检查。没有逐页扫描所有页面的可见文字，登录以外的 `/settings`、`/admin` 未看。
