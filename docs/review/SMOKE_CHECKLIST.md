# 真实流程冒烟清单（生成工作台、任务与版本历史、结果页）

给 A 在本机真实模型环境里跑，结果贴回 PR 或评论。每条写：看什么、期望是什么、结果（通过 / 不通过 / 说明）。期望依据 `docs/API_CONTRACT.md` 第 5 节与各页 spec；**我（B 的助手）没有在真实模型上跑过，期望是按文档写的，跑出来与期望不符时请先判断是文档过时还是实现问题，再贴回。**

准备：`python -m app.seed` 的演示品牌，品牌管理员账号；再准备一个编辑者账号用于 H 节。

## A. 生成工作台（`/generate`）
| # | 操作 | 期望 | 结果 |
|---|---|---|---|
| A1 | 打开页面，不选任何东西点生成 | 不发请求；必填项（商品、场景）有中文校验提示 | |
| A2 | 选商品、场景，填创作要求，点生成 | 创建任务后进入进度；阶段文案是中文（排队、生成、检查）；没有英文或原始枚举值 | |
| A3 | 创作要求写超限（简述 >2000） | 前端提示超限，不提交；计数器口径与契约一致 | |
| A4 | 任务资料添加 6 份（上限 5 份） | 被拦下并提示；单份超 50000 码点也被拦 | |
| A5 | 必含词里放一个资料里没有的词 | 生成结果里要么包含，要么约束检查明确说未满足，不静默丢掉 | |

## B. 生成中与失败态
| # | 操作 | 期望 | 结果 |
|---|---|---|---|
| B1 | 模型慢（等待 >30 秒） | 进度保持可见，不假死，没有无限转圈无说明 | |
| B2 | 模型不可用（临时用错误密钥） | 显示 503 对应的中文说明和请求编号，可重试；不显示 0 或空结果 | |

## C. 结果页（`/tasks/:id/versions/:versionId`）
| # | 看什么 | 期望 | 结果 |
|---|---|---|---|
| C1 | 标题、正文、标签与字数 | 标题加权 ≤20（ASCII 0.5、其余 1，emoji 2）；正文去换行后 UTF-16 码元 ≤1000；标签 ≤10；与发布页一致 | |
| C2 | 事实证据 | 每条断言能展开看到资料原文片段与版本；系统判定写“系统判定支持”，不写“已验证事实” | |
| C3 | 没有系统依据的断言 | 显示需要人工决定；成立才放行；确认后标注“人工确认，不是系统验证” | |
| C4 | 风险提示 | 命中的提示带来源与条款，标签是“风险提示”，没有“合规通过”之类结论 | |
| C5 | 页面全部文字 | 搜索“合规通过、已验证事实、法务批准、保证合规”，不应出现 | |
