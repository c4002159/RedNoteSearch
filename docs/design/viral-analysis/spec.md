- 对应需求：契约 10.1（爆款结构分析）。品牌成员添加样本、分析；品牌管理员可把结构转为场景模板
- 路由（建议）：`/viral-samples`（样本列表）、`/viral-samples/:id`（样本详情与分析）、`/viral-patterns/:id`（结构详情）
- 导航：放在“增强”分组，入口名“爆款结构分析”；导航归 A，B 只提议，不改（见 CLAUDE.md）
- 负责人：B（设计与实现）；后端由 A 与 AI 助手负责

## 状态清单
样本列表：加载中、空、正常。添加：正常、文本为空 / 超长、链接无效。分析窗口：选择模型、等待中、请求超时、422、503。结构列表：空、正常。转换：正常、成功、403。404。

## 区域与字段
**样本列表**（`GET /brands/{brand_id}/viral-samples`，排序 `±created_at`）：摘要（`excerpt`，前 200 字）、字数 `char_count`、添加时间；列表不含全文。
**添加样本**（`POST …/viral-samples`）：文本 1–5000 字（显示字数计数）；备注选填 ≤1000；来源链接选填 ≤2000，须 http 或 https。
**样本详情**（`GET /viral-samples/{id}`）：全文、备注、来源链接。**来源链接只作纯文字显示，不做成可点击链接。** 已分析的结构列表来自 `GET …/patterns`。
**分析**（`POST /viral-samples/{id}/analyze`，体 `{model_id}`，同步，成功 201）：通常 20–90 秒，前端超时设置 ≥120 秒，所以必须有等待状态：显示已等待秒数、按钮不可点、不提供取消。网络层超时后，界面**先提示去读取结构列表核对**，没有新结果再重试，避免重复分析。
**结构详情**（`GET /viral-patterns/{id}`）：`title_pattern`、`hook_type`、`tone`、`emoji_usage`、`hashtag_usage`、`paragraph_structure`（1–20 段，按有序列表显示）、`abstract_template`（≤5000，**按纯文本段落显示，不渲染占位符、不当可填充模板**）、`model_id`、`prompt_version`、`checker_version`。
**转为场景模板**（`POST /viral-patterns/{id}/to-template`，体 `{name 1–100, scene}`，仅品牌管理员）：场景 `seeding`、`review`、`tutorial`、`launch`、`promotion`、`story`；成功返回 `structure` 与 `template_version`；编辑者调用返回 403。

## 交互
- 分析成功后跳到新结构的详情，或刷新结构列表。
- 分析失败：422 `INVALID_MODEL_OUTPUT`（`details.reason`：`schema_invalid`、`copied_text`、`format_invalid`）、503 `MODEL_UNAVAILABLE`；校验错误 422 `VALIDATION_ERROR`。
- 只有 401 才退出登录；403、404 沿用公共组件。

## 用到的组件
表格与分页、居中弹窗、输入框、下拉、错误条加请求编号复制、骨架、空状态、加载圈。没有新增 token；超时提示条用既有的提示黄色。

## 已决定
- 来源链接纯文字、`abstract_template` 纯文本（A 的要求）。
- 分析是同步长请求，必须画等待状态与超时后的核对提示（A 的要求）。
