## 区域与字段
- 品牌名与角色：`GET /brands` 每项的 `name`、`role`。
- 当前用户：`GET /users/me` 的 `full_name`、`email`、`is_superuser`。
- 导航分组与顺序：技术文档表 4-3。导航不渲染无权限的项（不是置灰）。
- 错误的请求编号来自错误响应的 `request_id`，未知时显示"—"。

## 交互
- 品牌切换后，导航按新品牌里的 `role` 重新计算；当前页若无权访问，显示 403 页并给返回入口。
- 平台管理员不是品牌成员时，顶栏显示"未选择品牌"，导航只显示品牌与切换、合规规则、用户设置、用户管理（A 已核对）。
- 分组标题可折叠；&lt;1280px 侧栏收成图标栏。

## 用到的组件与 token
见 design-tokens 与 common-components；本批没有在页面里写色值之外的新值。
