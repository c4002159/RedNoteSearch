## 区域与字段（契约第 2 节）
- 我的资料：`GET /users/me`（`id`、`email`、`full_name`、`is_superuser`）读取；`PATCH /users/me` 保存姓名。邮箱只读（提示“邮箱由管理员录入，不可直接修改”）。
- 修改密码：`PATCH /users/me/password`，三个输入框；“新密码”与“确认新密码”必须一致才可提交（前端校验）。
- 登录：`POST /login/access-token`，表单字段邮箱（作为用户名）与密码；错误凭据 401，不泄露哈希。
- 登录页页脚：“账号由平台管理员创建，不提供自助注册”（契约：`/users/signup` 必须关闭）。

## 交互
- 保存按钮在表单没有变化时禁用。
- 401 只在登录页提示“邮箱或密码不正确”；其他页面里的 401 才触发退出登录并回到登录页（前端只在 401 登出）。
- 错误条显示 `request_id`（FC-07）；“请求编号”可复制（公共组件）。
- 不放主题、语言、通知、删除账号：这些功能没有实现（技术文档 4.2 不放未实现功能的入口）。

## 用到的组件与 token
输入框、密码显隐、按钮（主、次、禁用）、成功提示、错误条加请求编号、页签；沿用 design-tokens 与 common-components，没有新增 token。错误条**不使用“风险提示”标签**，该词只用于合规风险提示。
