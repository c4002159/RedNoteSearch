## 区域与字段
- 我的品牌（`GET /brands`，响应 `{"items":[{"id","name","category","role"}]}`，按名称排序）：品牌名、类目、我的角色（admin 显示“品牌管理员”，editor 显示“编辑者”）、当前品牌标记；非当前品牌有“切换到此品牌”。平台管理员也只看到自己是成员的品牌。
- 新建品牌：仅平台管理员可用（`POST /brands`）；对非平台管理员，设计里只是示意禁用态，实现时直接不渲染。
- 成员管理（`GET /brands/{brand_id}/members`、`POST …/members`、`PATCH …/members/{user_id}`、`DELETE …/members/{user_id}`）：姓名、邮箱、角色下拉（`admin|editor`）、“移除”。最后一位 admin 不可移除或降级（409）。
- 添加成员弹窗：用户邮箱 + 角色；成功 201；用户不存在 404；已是成员 409；角色不合法 422。

## 交互
- 切换品牌：更新顶栏里的当前品牌，其余页面按当前品牌重新取数；本页不改请求体里的 `brand_id`（FC-09，授权来自服务端 `brand_member`）。
- 修改角色、移除成员后重新请求成员列表；409 显示错误条加 `request_id`（不使用“风险提示”标签）。
- 只有 401 才退出登录；品牌路径下非成员 403，不渲染该品牌数据。

## 用到的组件与 token
卡片、状态徽标（当前品牌、角色）、表格、下拉、居中弹窗、错误条加请求编号、空状态；沿用 design-tokens 与 common-components，没有新增 token。
