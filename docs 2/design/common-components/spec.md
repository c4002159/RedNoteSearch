## 区域与字段
- 确认弹窗被拒原因：错误响应 `INVALID_STATE` 的 `details.current_state`、`details.codes`、`details.reasons[]`。**界面只显示 `details.reasons[]` 的可读文字；`codes`（如 `unconfirmed_claims`、`not_latest_version`）只用来让前端判断按钮状态，不展示给用户。** 不自行编造原因。
- 错误态：错误信封 `{error:{code,message,details,request_id}}`；请求编号未知时显示“—”。
- 上传限制：PDF、DOCX ≤50 MB；md、txt、csv ≤5 MB；`FILE_TOO_LARGE` 的 `details.limit_bytes`；`UNSUPPORTED_FILE_TYPE` 的 `details.allowed`；`PARSE_FAILED`。
- 状态徽标的文案与色调取自技术文档表 4-4；“人工确认（非系统验证）”按 #32。

## 字数组件（自定义计数）
字数组件不能只做“字符数 / 上限”，计数方式由调用方传入：
- **标题**：按加权长度，ASCII 可打印字符计 0.5，其余计 1（表情符号按 UTF-16 码元逐个计，计 2），上限 20，显示如 `18.5 / 20`（ADR-004）。
- **正文**：去换行后的 UTF-16 码元数，上限 1000；标签的可见字符计入正文。显示如 `412 / 1000`。
- **标签**：个数，上限 10，显示 `已选 N / 10`；另有必含词标签选择（≤20 条）。
- 超限变红并带“超出上限”文字，不截断（与发布页行为一致，ADR-004 实测）。图 01 的示例：标题 `12.5 / 20`、超限 `21 / 20`、正文 `412 / 1000`、标签 `已选 2 / 10`。

## 新增组件说明（05 图）
- **开关**（启用/停用规则）：关闭 = 停用，不是删除；无权限时禁用并写出原因；提交中显示“正在保存…”。
- **日期选择**（规则的生效与失效日期）：输入框 + 日历浮层；失效日期不能早于生效日期（错误态文字提示）。
- **标签页**：选中下划线加主色字；左右键切换；可带数量。
- **右侧抽屉**（结果页证据与风险面板）：≥1280 为页内右栏，1024 折成抽屉；点遮罩、Esc、关闭按钮收起，焦点回到打开按钮。
- **阶段进度条**：排队、生成中、检查中；取自 `progress.stage`，轮询更新，只显示阶段，不显示假百分比；失败时显示原因与请求编号。
- **表格筛选栏**：搜索 + 下拉筛选 + 清除筛选；已选条件显示为可移除标签；无结果显示空态。
- **带“原因”输入的停用确认弹窗**（停用资料、停用规则）：原因必填，为空时“停用”禁用，提交时为空显示错误；说明“停用不是删除”。
- **请求编号“复制”小组件**：默认、悬停、焦点、复制成功、复制失败、编号未知（无复制按钮）。

## 交互
- 表单提交中按钮显示加载并不可再点。
- 仅 401 退出登录；403、404 不退出。
- 错误态带重试。
- **长时间解析**：知识库上传和 F12 都是同步的，请求一直等到解析和嵌入完成才返回，**没有“解析中”状态可轮询，也没有后台任务**。界面提示“解析大文件可能需要几分钟，请保持本页面打开，直到完成”；不写“自动更新”，不显示假进度。
